Beta Charter

The beta runs for 4 weeks with these goals:

  • Scope: Grounded recall, simulation fence, causal simulation
  • Success bar: Zero contamination incidents during beta
  • Feature flags: New features behind MEM20_FLAG_* toggles — off by default for 1.0 compatibility
  • Support: Direct channel to the team, /metrics walkthrough, contamination report process
